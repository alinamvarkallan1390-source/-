✦ مستندات ربات نکسورا

راهنمای نسخهٔ اولیهٔ API ربات · ASP.NET Core 8

رابطی که روی Vercel منتشر می‌شود فقط یک دموی محلی است و توکن واقعی تولید نمی‌کند. API زیر نیاز به اجرای جداگانهٔ بک‌اند ASP.NET دارد. این نسخه هنوز برای استفادهٔ عمومی یا اطلاعات حساس آماده نیست.

۱. ساخت ربات

در کلاینت متصل به بک‌اند، وارد حساب شوید و از دکمهٔ «ساخت ربات» استفاده کنید. نام کاربری انگلیسی باید با _bot تمام شود. توکن فقط یک‌بار نمایش داده می‌شود؛ مثل رمز عبور محرمانه نگهش دارید.

یا با API حساب کاربری:

curl -X POST "$BASE/api/bots" \
  -H "Authorization: Bearer $USER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"username":"hello_bot","displayName":"Hello Bot"}'

خروجی شامل id، username و token است. توکن حساب کاربری و توکن ربات با هم فرق دارند. ربات نمی‌تواند به کاربری که هنوز چت با آن را ایجاد نکرده پیام بفرستد.

۲. شروع گفتگو و دریافت پیام

کاربر در نکسورا با نام کاربری ربات گفتگویی می‌سازد و پیام می‌فرستد. برنامهٔ ربات سپس با polling پیام‌ها را می‌خواند:

curl "$BASE/api/bot/updates?offset=0" \
  -H "Authorization: Bearer $BOT_TOKEN"

خروجی آرایه‌ای با فیلدهای updateId، chatId، fromUserId، text و createdAt است. در درخواست بعدی، بزرگ‌ترین updateId پردازش‌شده را به عنوان offset بفرستید. پاسخ‌ها حداکثر ۱۰۰ پیام دارند. offset را بعد از پردازش موفق به‌طور پایدار ذخیره کنید تا تکرار یا از دست رفتن پیام مدیریت شود.

۳. ارسال پاسخ

curl -X POST "$BASE/api/bot/messages" \
  -H "Authorization: Bearer $BOT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"chatId":1,"text":"سلام از ربات نکسورا!"}'

به جای ۱ شناسهٔ واقعی گفتگو را از update بگذارید. متن باید بین ۱ تا ۴۰۰۰ کاراکتر باشد. ربات فقط به گفتگوهای خودش دسترسی دارد.

نمونهٔ ساده با Node.js ۱۸+

متغیرهای محیطی BASE و BOT_TOKEN را در محیط امن تنظیم کنید. این مثال صرفاً آموزشی است؛ offset بعد از restart حفظ نمی‌شود.

const base = process.env.BASE;
const token = process.env.BOT_TOKEN;
let offset = 0;
async function request(path, options = {}) {
  const res = await fetch(base + path, {
    ...options,
    headers: { Authorization: `Bearer ${token}`,
      'Content-Type': 'application/json' }
  });
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}
async function run() {
  while (true) {
    try {
      const updates = await request(`/api/bot/updates?offset=${offset}`);
      for (const u of updates) {
        await request('/api/bot/messages', {
          method: 'POST',
          body: JSON.stringify({chatId: u.chatId, text: `سلام! گفتی: ${u.text}`})
        });
        offset = u.updateId;
      }
    } catch (error) { console.error(error.message); }
    await new Promise(resolve => setTimeout(resolve, 3000));
  }
}
run();

محدودیت‌ها و امنیت

در این نسخه webhook، دکمه، فایل، گروه، کانال، پرداخت، مدیریت توکن و رمزنگاری سرتاسری وجود ندارد. برای محیط واقعی HTTPS، ذخیره‌سازی پایدار، کنترل نرخ بر اساس IP و حساب، بازیابی و چرخش توکن، لاگ امن، مانیتورینگ و بازبینی امنیتی لازم است. هرگز توکن را در کد سمت مرورگر یا مخزن عمومی قرار ندهید. این API با Bot API تلگرام سازگار نیست.
