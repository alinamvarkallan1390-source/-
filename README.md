# نوا

نمونهٔ اولیهٔ رابط فارسی پیام‌رسان. گفتگوها و ربات‌های پاسخ‌گوی ساده فقط در localStorage همان مرورگر ذخیره می‌شوند؛ این پروژه هنوز پیام‌رسان چندکاربره، حساب کاربری، سرور پیام، رمزنگاری یا API ربات ندارد و برای داده‌های حساس مناسب نیست.

برای اجرا، فایل `index.html` را با یک سرور فایل استاتیک باز کنید. استقرار بدون مرحلهٔ ساخت روی Vercel پشتیبانی می‌شود.
