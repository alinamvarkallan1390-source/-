# نکسورا

یک نمونه اولیهٔ پیام‌رسان فارسی با دو بخش مجزا:

* `index.html`: دموی رابط کاربری استاتیک برای Vercel. پیام‌ها و ربات‌های پاسخ خودکار تنها در مرورگر ذخیره می‌شوند؛ با بک‌اند ارتباطی ندارد.
* `backend/`: نمونه اولیهٔ ASP.NET Core 8 با SQLite و کلاینت متصل (`real.html` و `backend-client.js`). ثبت‌نام، ورود، گفتگوی مستقیم، پیام متنی، ساخت ربات، دریافت پیام ربات با polling و ارسال پاسخ را پیاده‌سازی می‌کند. این بخش جداگانه اجرا می‌شود و با دموی Vercel یکی نیست.

## اجرای بک‌اند و کلاینت متصل

نیازمند .NET SDK 8 و دسترسی به NuGet:

```sh
cd backend
dotnet restore
dotnet run
```

آدرس نمایش‌داده‌شده توسط برنامه را باز کنید. فایل SQLite به صورت پیش‌فرض در پوشهٔ backend ساخته می‌شود. اتصال را می‌توان با `ConnectionStrings__Nexora` تنظیم کرد. برای نمونه‌سازی ربات، در رابط متصل یک ربات بسازید، توکنش را ذخیره کنید، با نام کاربری آن گفتگو بسازید و به آن پیام بدهید. مستندات در `/docs/bots.html` در دسترس است.

## محدودیت‌ها

این محصول کامل یا آمادهٔ تولید نیست: امنیت و همزمانی نیازمند بررسی و تست، HTTPS و زیرساخت پایدار است؛ پیام‌ها رمزنگاری سرتاسری ندارند. گروه، کانال، مدیا، تماس، اعلان، وب‌هوک، جستجوی سمت سرور، مدیریت نشست و بازیابی حساب هنوز پیاده‌سازی نشده‌اند. SQLite محلی روی محیط‌های serverless پایدار نیست. Vercel میزبان معمول ASP.NET Core نیست؛ بک‌اند باید در سرویس پشتیبان .NET به‌صورت جداگانه مستقر شود. ادغام دموی Vercel با آن هنوز انجام نشده است.

## ساخت و آزمون دموی وب

```sh
npm ci
npm test
npm run build
```

خروجی استاتیک در `public/` ساخته می‌شود؛ فقط فایل‌های دمو و مستندات در آن قرار دارند، نه کد بک‌اند یا کلاینت متصل. تست‌های مرورگر شبیه‌سازی‌شده ارسال، ویرایش و حذف پیام محلی، ساخت ربات نمایشی، پیام‌های ذخیره‌شده، حالت شب، جستجو و escape متن را بررسی می‌کنند.
